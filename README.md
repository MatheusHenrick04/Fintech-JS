# 🏦 Fintech JS - Gestão de Filas e Atendimento

Projeto em JavaScript desenvolvido para praticar a implementação de **Estruturas de Dados (Fila / FIFO)**, funções de processamento, manipulação dinâmica de arrays e laços de repetição aplicados a um sistema simulado de atendimento bancário.

## 📌 Funcionalidades e Ficheiros

- **Atendimento Básico (`atendimento.js`):**
  - Processamento sequencial de clientes numa fila utilizando o método `.shift()`.
  - Controlo de fluxo com laço `while` e contagem de posições.

- **Atendimento com Verificação (`atendimento2.js`):**
  - Evolução do sistema com modularização através da função `exibirFila()`.
  - Verificação do estado da fila (`fila.length == 0`) para tratar estados vazios.

- **Listagem e Adição de Clientes (`forOf.js`):**
  - Iteração sobre listas de clientes utilizando o laço `for...of`.
  - Inserção dinâmica de novos elementos com o método `.push()`.
